# Brand assets: official files needed

> **Use only official Las Trampas Seahorse / Las Trampas Pool marks.** Don't redraw, trace, or recreate logos, and don't add vector illustrations.

---

## Needed from the Las Trampas Seahorses (ltst.org) and the pool board

| File | Format | Notes |
|---|---|---|
| Seahorse primary logo | Original master (AI/EPS/SVG/PDF) as supplied + PNG with transparent background (≥ 1024 px) | Full color |
| Seahorse logo, one-color | Same | White and navy versions for dark/light bands |
| Pool wordmark / logo (if one exists) | Same | Otherwise we'll use a typographic wordmark |
| Favicon / app icon source | PNG ≥ 512 px, square | For PWA icon |
| Official colors | Hex/RGB/Pantone | Replaces the suggested palette in `design/BRAND.md` |
| Usage guidelines | PDF or notes | Clear space, minimum size, don'ts |

## Permission

- **Who owns the Seahorse marks?** Likely the swim team; to confirm.
- Get **written permission** for the pool site to use them (scope: website, emails, app icon).
- Record the permission (who, date, scope) in `PERMISSION.md` in this folder once received.

Note: "official vector logo files" are fine. The no-vector rule is about **illustrations and decorative artwork**, not the official logo masters.
