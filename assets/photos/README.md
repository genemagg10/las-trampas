# Photos: real Las Trampas photos needed

> **No stock photos and no illustrations in the live site.** Files here must be real photos of Las Trampas Pool with permission to use them. The images in `design/mockup/` are stock placeholders only.

---

## Needed shots

| Use | Subject | Orientation / min size |
|---|---|---|
| Home hero | Pool on a sunny day, lawn and deck | Landscape, ≥ 2400 px wide |
| Lap swim | Lap lanes (ideally early morning), lane lines, empty or adult swimmers | Landscape, ≥ 1600 px |
| Socials | Opening Party, June/July BBQ, Las-Toberfest, Halloween swim | Landscape, ≥ 1600 px |
| Volunteering | Maintenance days, grill crew (adults) | Landscape, ≥ 1600 px |
| Swim team | Seahorses meets and practices (consent required for minors) | Landscape, ≥ 1600 px |
| Facilities | 6-lane 25-yd pool, diving well, baby pool, lawn, clubhouse | Mixed |
| History | Archive photos from 1958 onward | Scans ≥ 300 dpi |
| Membership | Families on the lawn (consented) | Landscape |

## Requirements

- **Permission** from the photographer (name for credit, if wanted).
- **Consent** from identifiable people per the club's photo policy; no identifiable children on public pages without guardian opt-in.
- Original JPG/HEIC; we'll generate web sizes.
- Add each file to `CREDITS.md` here: filename, photographer, date/event, consent status, allowed use (`public` / `members-only`).

## Where photos live

Event albums uploaded by members live in **Supabase Storage**, not git. This folder is only for the small set of curated site photos (heroes, section images).
